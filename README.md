# EchoBite AI - React.js + Vite Application

A modern, fully functional food ordering application built with React.js and Vite. Features voice ordering, cart management, user authentication, and an admin dashboard.

## 🚀 Features

- **Voice Ordering**: Use AI voice recognition to order food
- **Smart Menu**: Search, filter, and sort food items
- **Shopping Cart**: Add/remove items with quantity control
- **User Authentication**: Login and signup functionality
- **Checkout System**: Complete order checkout with delivery options
- **Admin Dashboard**: View orders, revenue, and user statistics
- **Responsive Design**: Fully optimized for mobile and desktop
- **Toast Notifications**: Real-time user feedback
- **LocalStorage Persistence**: Cart and user data saved locally

## 🛠️ Tech Stack

- **React 18**: Modern React with Hooks
- **Vite**: Ultra-fast build tool
- **React Router v6**: Client-side routing
- **CSS3**: Modern styling with animations
- **Web Speech API**: Voice recognition

## 📦 Quick Start

### Prerequisites
- Node.js v14+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The app will open at `http://localhost:5173`
